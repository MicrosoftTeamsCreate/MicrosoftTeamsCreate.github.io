TeamStart

Sign in with your work account to provision a new Microsoft Team — channels, a shared Resource Hub library, and group-based folder permissions, all in one pass.

TeamStart

Team details

The basics — this becomes the Microsoft 365 group and Team name. Teams created here are always private.

Additional owners

You'll automatically be made an owner of the team, its private channels, and the Resource Hub library — this is only for adding anyone else alongside you.

Anyone added here also gets write access to the Workbench folder, Knowledge Base, and Vault — the same access level you get as the creator, not the more limited access the group-based permissions below give everyone else.

Channels

Choose how many channels to create, then name each one and pick Standard or Private.

Channel 1 becomes the team's first channel — if it's Standard, it takes that name directly instead of Teams' default "General". If Channel 1 is Private, a "General" channel is created automatically alongside it (Teams requires at least one standard channel), and your named channel is created as private separately.

Resource Hub library

A shared document library with Knowledge Base and Vault folders, pinned as a tab in every channel.

This tool sets up owners only. To add regular members to the team, do that manually in Teams once it's created — same for adding people to private channels beyond the owners above.
